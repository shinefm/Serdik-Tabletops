# Serdik Games

Game papan online untuk P3MD. Halaman statis (index.html) + Firebase (login Google, Firestore, Realtime Database).

- `index.html` — game
- `shim.js` — penghubung game ke Firebase
- `firebase-config.js` — konfigurasi publik Firebase
- `fb/` — Firebase SDK v10.14.1 (compat)
- `firestore.rules`, `database.rules.json` — aturan keamanan (ditempel manual di konsol Firebase)
